# Expansion branding

`30th-celebration.png` is the official English 30th Celebration anniversary logo served by TCGdex:
https://assets.tcgdex.net/en/me/30th/logo.png

Retrieved October 18, 2026. The PNG is available while the corresponding WebP returns 404.
It is bundled as a fallback for `30th` and, with a `CLASSIC` caption, `30th-c` when no working set-specific branding is supplied. This shared anniversary mark is not presented as a distinct official Classic Collection logo. API-supplied working logos take priority. No card illustration is used as expansion branding.
